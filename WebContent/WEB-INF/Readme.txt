================================================================================
  SCUOLAWEB — GUIDA ALL'AVVIO
================================================================================

1. DATABASE
-----------
Apri nel browser: http://localhost/phpmyadmin/index.php?route=/server/databases ed esegui in ordine:
  - creazione del database con il nome progetto_scuola
  - poi il file SQL: creazione_db.sql
  - infine il file SQL: inserimento_dati.sql

2. AVVIO
--------
In Eclipse, vai nella scheda "Servers" in basso 
e dopo aver configurato il server tomcat, tasto destro su
"Tomcat v8.5 Server at localhost" e clicca "Start".
Attendi che lo stato diventi [Started].

3. ACCESSO
----------
Apri il browser e vai su:

   http://localhost:8080/ScuolaWeb/index.html

Si aprirà la pagina di login.
